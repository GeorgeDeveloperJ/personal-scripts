# Tecnologías

1. **Bash Scripting**: Utilizo scripts en bash para automatizar tareas repetitivas
como el levantamiento de repositorios o dinamizar layouts en zellij.

2. **KDL files**: Utilizo .kdl como template de zellij para monitorear logs
de diferentes archivos al mismo tiempo. Con las ventajas de un multiplexer
solo ejecutando el script de bash.
